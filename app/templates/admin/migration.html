2. User Migration Strategy

{{ lucide_icon("key-round", "h-7 w-7 flex-shrink-0 text-orange-300") }}
Temporary Passwords

Since Parker uses different encryption than Kavita, user passwords cannot be migrated directly.

  • New users will be created with random temporary passwords.
  • New users must set a new password the first time they log in.
  • Re-imports match existing Parker users by username and keep their account and password unchanged.
  • For matched comics, re-imports add new progress and only advance existing progress.
  • If new users are created, a CSV file containing their credentials will automatically download.
  • You must securely distribute these passwords to your users.
