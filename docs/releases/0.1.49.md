# Parker 0.1.49 Release Notes

Status: Draft

## Added

- Added deep links to the admin Settings page. `/admin/settings#<category>`, such as `#server`, opens that section and scrolls to it, and `/admin/settings#<setting key>`, such as `#server.update_check_enabled`, opens the setting's section, scrolls to it and briefly outlines it. This works on phones, where sections start collapsed, and when the link changes while Settings is already open, such as from the notification bell. A setting hidden because the setting it depends on is off falls back to its section, and unknown targets are ignored. What's New entries about a setting can now take admins straight to it.

## Changed

- The 0.1.48 What's New entries now link straight to the settings they mention: Update notifications to **Check for Updates**, Notification settings to **Enable Notifications**, and Notifications to the Notifications section of Account Settings.
- The "Downloads are turned off site-wide" note in Admin → Users now links straight to **Allow Comic Downloads** instead of the top of Settings.
