# Parker 0.1.49 Release Notes

Status: Released

## Added

- Added pinned reading lists. A **Pin to Home** button on a reading list's page adds it to a new **Pinned Reading Lists** rail on Home, with one card per list. Each card opens the reader at the list's next unread issue (the same issue the list's Continue button picks) and shows a progress bar with how many issues are read. Finished lists leave the rail but stay pinned, so they come back if new issues are added. Lists the reader has been reading show first, newest first, followed by lists not started yet in the order they were pinned. Pinned lists show a **Pinned** badge on the Reading Lists page. Pins follow the usual library access and age-rating rules, and a pin is removed when its list or user is deleted. The rail can be moved or hidden like the other Home rails.
- Added shift-click range selection to comic grids and Home rails. With a comic selected, shift-clicking another selects every issue between the two, in the order the grid shows them. Shift-clicking a comic that is already selected deselects that range instead. A range stays within one grid or rail, so on Home it never spans rails. Shift-click also starts a selection when nothing is selected yet.
- Added deep links to the admin Settings page. `/admin/settings#<category>`, such as `#server`, opens that section and scrolls to it, and `/admin/settings#<setting key>`, such as `#server.update_check_enabled`, opens the setting's section, scrolls to it and briefly outlines it. This works on phones, where sections start collapsed, and when the link changes while Settings is already open, such as from the notification bell. A setting hidden because the setting it depends on is off falls back to its section, and unknown targets are ignored. What's New entries about a setting can now take admins straight to it.

## Changed

- While any comic is selected, clicking a cover selects or deselects it instead of opening the reader, so a near miss on the checkbox no longer launches the reader. Ctrl-click and Cmd-click still open the comic in a new tab, and the issue title under the cover still opens the issue page. Clearing the selection brings back the usual click-to-read.
- The 0.1.48 What's New entries now link straight to the settings they mention: Update notifications to **Check for Updates**, Notification settings to **Enable Notifications**, and Notifications to the Notifications section of Account Settings.
- The "Downloads are turned off site-wide" note in Admin → Users now links straight to **Allow Comic Downloads** instead of the top of Settings.
- The library folder watcher now updates its watch list under a lock. Today its callers never overlap, but once the library routes stop being `async`, two library changes saved at once could otherwise watch the same folder twice or remove the same watch twice.
