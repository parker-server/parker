# Parker 0.1.43 Release Notes

Status: Unreleased

## Added

- Added administrator-managed Featured Rails for Home. Each rail has a title, enabled state, display order, start date, optional end date, and an Advanced Search query; readers can hide individual featured rails through Customize Home.
- Added a View matching issues handoff from Featured Rails to public Advanced Search, with the rail query exposed for readers to inspect and refine.
- Added paginated series browsers for the Recently Added Series and Recently Updated Series Home rails, preserving each rail's membership, ordering, and volume-cover behavior beyond the first row.
- Added Defiant publisher logo.

## Changed

- Refactored the Advanced Search builder into a reusable query-builder surface so it can be embedded in feature-specific workflows, including Featured Rail administration, without inheriting public saved-search or Smart List controls.
- Kavita-imported users created with temporary passwords must now change their password on first login.
- Kavita progress imports now preserve Kavita's UTC timestamp when present and fall back to its legacy timestamp when it is missing.

## Fixed

- Fixed Advanced Search returning comics outside a non-administrator's accessible libraries. Search results now apply the same library access boundary as the rest of Parker.
- Fixed Advanced Search genre autocomplete so it now correctly suggests genres from accessible, age-permitted comics.
- Fixed the Recently Added/Updated home rail's 'View All' links to now direct to the new series browser page.  These links were previously directing the user to an empty advanced search query.
