# Parker 0.1.41 Release Notes

Status: Draft

`0.1.41` is an in-progress release draft.

## Added

- Added revocable per-user OPDS keys for external reader apps. Users can create named keys from Account Settings, copy the raw key once, use it as the OPDS Basic Auth password with their normal Parker username, and revoke keys later without changing their main account password.

## Changed

- Moved OPDS key management to a dedicated account page, with compact dashboard and settings links for the feed URL and active key count. The account settings entry point and key manager route are hidden when OPDS is disabled.

## Fixed

- Hardened direct series/comic ID access paths so OPDS series feeds, API series issue lists, series starring, recommendation source selection, and batch read-status updates no longer expose or mutate comics from libraries the current user cannot access. Series issue lists and batch read-status updates now also respect Parker's series-level age restrictions, and batch responses count only authorized comics that were actually targeted.
