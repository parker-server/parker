## Fixed

- Hardened direct series/comic ID access paths so OPDS series feeds, API series issue lists, series starring, recommendation source selection, and batch read-status updates no longer expose or mutate comics from libraries the current user cannot access. Series issue lists and batch read-status updates now also respect Parker's series-level age restrictions, and batch responses count only authorized comics that were actually targeted.
