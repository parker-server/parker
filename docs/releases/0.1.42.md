# Parker 0.1.42 Release Notes

Status: Unreleased

## Added

- Added an enabled-by-default Appearance setting for showing volume dividers in the flat Series Issues tab.

## Changed

- Series issue responses now identify the first displayed issue of each new volume so dividers remain correct with filters, reverse sorting, infinite scroll, and classic pagination.

## Fixed

- Fixed the Series Issues volume divider layout so the visual marker sits in the grid gap without changing the width or height of the adjacent comic card.

## Validation

- Verified the series API and settings behavior: `64 passed` via `.\.venv\Scripts\python.exe -m pytest tests/api/test_series.py tests/api/test_settings.py -q`.
- Verified the divider display, toggle, and equal card-height behavior with Playwright via `.\.venv\Scripts\python.exe -m pytest tests/browser/test_search_and_series_smoke.py::test_series_issues_mark_new_volume_boundaries -q`.
