# Parker 0.1.42 Release Notes

Status: Released

## Added

- Added an enabled-by-default Appearance setting for showing volume dividers in the flat Series Issues tab.
- Added an info button and mobile-friendly modal on static-cover login backgrounds with curated context for the selected cover.
- Added a color-swatch preview for Login Solid Color choices on the admin Settings page.
- Added Impact Comics imprint logo.

## Changed

- Series issue responses now identify the first displayed issue of each new volume so dividers remain correct with filters, reverse sorting, infinite scroll, and classic pagination.

## Fixed

- Fixed watch mode detection for metadata editors that rewrite comic archives through temporary files, such as edits made over a Samba share, so destination archive changes are not discarded as temp-file noise and repeated filesystem events are coalesced into a single queued scan.
- Fixed external review refreshes from async contexts, such as after browser tests have touched the main thread event-loop state, so ComicBookRoundup lookups no longer fail when an event loop is already running.
- Fixed Recently Added Series on the home page and OPDS root shortcut so existing series with newly imported issues stay in Recently Updated instead of being treated as newly added series.
