# Parker 0.1.26 Release Notes

Status: Released

`0.1.26` is Parker's CBL reading-list release. It adds Parker-managed CBL files as a first-class reading-list source, giving users event and crossover reading orders without requiring complete `AlternateSeries` / `AlternateNumber` metadata or write access to comic archives.

## Added

- Added first-class CBL reading-list support backed by Parker-managed CBL source files stored under the writable Parker storage area.
- Added `cbl_sources` persistence for imported CBL files, including original filename, managed storage path, origin, catalog metadata, refresh status, fingerprint, entry count, and match summary.
- Added explicit reading-list provenance with `manual`, `comicinfo`, and `cbl` sources, replacing the older `auto_generated` boolean model for reading lists.
- Added admin APIs for listing, uploading, direct-URL importing, refreshing, and deleting managed CBL sources.
- Added a new Admin > CBL Reading Lists page for managing CBL sources, reviewing match status, renaming derived lists, refreshing sources, deleting sources, importing from URL, and browsing the built-in catalog.
- Added DieselTech/CBL-ReadingLists catalog browsing, preview, and import support through the GitHub Contents API.
- Added catalog previews that show the CBL name, entry count, warnings, and the first 10 reading-order entries before import.
- Added CBL parsing support for ComicRack-style files, preserving reading order and collecting non-fatal warnings for imperfect entries.
- Added CBL matching against Parker comics using series, issue number, volume, and year metadata, with deterministic handling for unmatched and ambiguous entries.
- Added automatic CBL source rebuilds after library scans so newly imported or rescanned comics can satisfy previously unmatched CBL entries.
- Added optional discovery/import of `.cbl` files found under library roots while still copying them into Parker-managed CBL storage.
- Added `CBL Derived` labels for reading lists created from managed CBL sources.
- Added CBL fixtures and focused API, service, scanner, and browser coverage for parser, matcher, source lifecycle, catalog import, and admin UI flows.

## Changed

- Reading-list generation is now source-aware, so ComicInfo-derived reading lists only own `source="comicinfo"` memberships and no longer overwrite or remove manual or CBL-derived memberships.
- ComicInfo-derived list creation is scoped by reading-list source instead of name alone, preventing generated metadata sync from writing into an unrelated list with the same display name.
- CBL-derived reading lists use the managed CBL source as their lifecycle owner. Refreshing a source updates only its derived list, and deleting a source removes its managed file and derived list together.
- Empty generated reading-list cleanup now only removes empty ComicInfo-derived lists. Manual and CBL-derived empty lists are preserved because their lifecycles are owned elsewhere.
- Generic reading-list deletion is now admin-only, and CBL-derived lists must be deleted through the CBL source endpoint instead of the generic reading-list endpoint.
- Direct URL CBL imports are HTTPS-only, stream with a size cap, disable redirects, validate resolved addresses, and pin the connection to a prevalidated address.
- URL and catalog refreshes preserve the last good CBL file when the remote source is unavailable, invalid, oversized, or no longer parses as CBL XML.
- Reading-list responses now expose `source` and `source_label` so UI surfaces can distinguish manual, Auto-Generated, and CBL Derived lists.
- The CBL implementation keeps event-level CBL files in dedicated Parker storage instead of treating comic series folders as the canonical home for cross-title reading orders.

## Fixed

- Fixed a reading-list collision hazard where ComicInfo-derived metadata could write comics into an existing manual or CBL list with the same name.
- Fixed a permissions gap where regular authenticated users could delete reading lists through the API.
- Fixed catalog-imported CBL refresh behavior by refreshing through stored catalog provider/path metadata rather than requiring a direct source URL.
- Fixed direct URL import DNS rebinding risk by validating DNS results and pinning the actual fetch to a validated resolved address.
- Fixed CBL refresh behavior so malformed refreshed content cannot replace the last successfully imported stored file.
- Fixed generic empty-list cleanup so it cannot orphan CBL sources by deleting their derived reading lists.
- Fixed generic reading-list deletion so it cannot orphan CBL sources by deleting only the derived list.
