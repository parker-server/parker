# Parker 0.1.40 Release Notes

Status: Draft

`0.1.40` starts with quick-search and thumbnail-generation correctness fixes.

## Added

- Added Alien Books publisher logo.

## Changed

- None yet.

## Fixed

- Fixed quick search showing the year a series row was created or imported instead of the series' publication start year. Series results now use the earliest positive issue year attached to the matching series, so older runs no longer show recent years such as 2025 or 2026 solely because they were imported recently.
- Fixed thumbnail generation failing on browser-tolerated truncated cover images, such as JPEG streams that still display in the reader but Pillow rejected while resizing the cover. Cover thumbnail generation, filtered page processing, and direct palette extraction now temporarily enable Pillow's truncated-image compatibility mode and restore the previous setting afterward.

## Validation

The sandboxed run hit the known `encodings` import error, and the repository-prescribed elevated retry passed.
