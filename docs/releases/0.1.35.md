# Parker 0.1.35 Release Notes

Status: Released

`0.1.35` is a focused patch release for smoother paged Reader Fit Width behavior, tagged-version update checks, metadata logo fallback fixes, and more robust archive cover ordering.

## Added

- Added browser coverage for scrolling tall pages in paged Fit Width mode while preserving reader edge-click navigation.
- Added an admin-only tagged-version check that shows update availability on the About page and badges the About card on the admin dashboard when a newer Parker tag is available.
- Added publisher logos for `AC Comics`, `Awesome Comics`, and `Valiant/Acclaim`.
- Added imprint logos for `Bravura` and `Windjammer`.

## Changed

- Paged Reader Fit Width mode now allows tall pages to scroll vertically inside the reading surface instead of trapping the reader at the top of an enlarged page.
- Fit Width mode now routes left and right edge clicks through the reading surface so page navigation remains available while the usual invisible navigation zones are disabled for scrolling.

## Fixed

- Fixed Fit Width reading for tall pages so readers can pan down the enlarged page and still advance to the next page from the right edge.
- Fixed publisher and imprint logo lookup so labels with filesystem/path symbols, such as `Valiant/Acclaim`, can fall back to sanitized logo filenames.
- Fixed archive page sorting so cover abbreviations like `cvr`, zero-prefixed cover names like `00Cover`, zero-letter cover pages like `00a`/`00C`, scanner exports like `00-36`, and leading-underscore twin covers are chosen before numbered interior pages without promoting inside-front-cover names like `00IFC`.
