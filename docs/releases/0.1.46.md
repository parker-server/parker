# Parker 0.1.46 Release Notes

Status: Draft

## Added

- Added a Change Cover option for admins on each comic's page, for covers the filename rules can't get right (wraparound covers, one-off archives). It shows the first 12 pages of the archive to pick from, takes an uploaded JPEG, PNG or WebP image (up to 10MB), and can reset to the automatic pick. The dialog shows which one is in use, and the thumbnail and cover colors update straight away.
- Added two comic columns for the manual cover: `cover_override_page` (the chosen page's filename in the archive, so cover sorting changes can't move it) and `cover_override_image` (the uploaded file, saved in `storage/cover_overrides/`) (migration `a7d3e9f2c4b1`).
- Added admin-only cover endpoints: `GET /api/comics/{id}/cover` lists the candidate pages and the active choice (previews use the reader's page endpoint), `PUT` sets a page by filename, `POST /api/comics/{id}/cover/upload` uploads an image, and `DELETE` resets to automatic. Each change regenerates that comic's thumbnail right away; if that fails the comic is marked for the next thumbnail task.
- Global cleanup deletes uploaded cover images whose comic no longer exists, for example after its file was moved, renamed or deleted. The count is included in the cleanup job's summary (`orphaned_cover_overrides_deleted`). Per-library cleanup leaves them alone.

## Changed

- Thumbnail generation now uses a comic's manual cover when it has one: the uploaded image first, then the chosen page, then the automatic pick. A chosen page that is no longer in the archive (for example after the file was replaced) falls back to the automatic pick without an error. Reader page order is unchanged.
- A manual cover survives rescans of the same file, and thumbnails regenerated after a rescan still use it. It is lost when the comic's file is moved, renamed or deleted, like reading progress.
- Cover Mural export uses a comic's manual cover too.

## Fixed

- Fixed the search index migration tests breaking whenever a column is added to comics. They seeded comics through the ORM model into databases at older revisions, so the insert named columns those revisions don't have. They now insert only the columns they need.
