# Parker 0.1.32 Release Notes

Status: Draft

`0.1.32` starts with Advanced Search fixes, field-aware rule operators, a mobile comic-detail layout adjustment, and a Reader magnifier tool.

## Added

- Added a rectangular Reader magnifier tool, available from the top toolbar or the `z` shortcut, that centers over the hidden pointer for closer page inspection without accidentally triggering paged navigation zones.

## Changed

- Advanced Search now offers rule operators based on the selected field, hiding impossible options such as empty library or series names and using numeric comparisons for release years.
- Advanced Search now normalizes loaded or deep-linked rules whose saved operator no longer applies to the selected field.
- Comic detail pages now move File Info below the main issue details on narrow mobile screens.
- Reader toolbar now hides the fullscreen button on touch-oriented devices where browser fullscreen support is inconsistent or redundant with the mobile reading experience.
- Reader toolbar actions now collapse into a compact overflow menu on small screens while keeping Close and the current issue title visible.

## Fixed

- Fixed Advanced Search creator `Not Equals` filters, including searches like `Penciller != Alex Ross`, so matching creator credits are excluded instead of the rule being ignored when combined with other filters such as `Language = en`.
- Fixed additional Advanced Search field/operator mismatches so genre empty checks, library name filters, and collection, reading-list, and stack negative/all-match filters build real backend conditions.
- Fixed the small-screen Reader toolbar overflow so Pin UI, Settings, and Bookmarks appear only in the overflow menu instead of being duplicated on the toolbar.
