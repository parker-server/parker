# Parker 0.1.37 Release Notes

Status: Draft

`0.1.37` improves thumbnail job diagnostics so warning-only image issues, including malformed EXIF metadata reported by Pillow, can be inspected from Job History without treating successfully generated thumbnails as failures.

## Added

- Added thumbnail job warning summaries and per-comic warning details to the admin Job History details modal, including comic ID, file path, warning type, and warning message.

## Changed

- Thumbnail workers now capture Python image-processing warnings during cover generation and save them into the job summary instead of leaving them as unattributed process log output.
- Warning-only thumbnail results remain successful thumbnail generations while still surfacing their diagnostic details separately from hard errors.

## Fixed

- Fixed thumbnail scan diagnostics for malformed image metadata warnings so admins can identify the affected comic file instead of seeing only a raw Pillow warning in server logs.

## Validation

- Verified thumbnail warning capture, thumbnail writer summaries, and job summary API behavior: `25 passed` via `.\.venv\Scripts\python.exe -m pytest tests\services\test_thumbnailer_service.py tests\api\test_jobs.py`.
- The sandboxed Python validation process failed to start with the known `encodings` import error, so validation used the repository-prescribed elevated retry.
