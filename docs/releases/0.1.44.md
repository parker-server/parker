# Parker 0.1.44 Release Notes

Status: Released

## Added

- Added a `template_error()` Jinja global that raises a template error at render time, so shared macros can reject invalid argument combinations instead of rendering broken markup.
- Added a staged, required preview for Kavita migrations. It summarizes new and matched users plus importable progress before the same uploaded database can be migrated; the shared cache-backed stage works across app workers and expired files are cleaned during startup.
- Added comic file downloads. Readers can save the original comic file from the Download option in the issue page's Read menu.
- Added an **Allow Comic Downloads** setting (on by default) to turn downloads on or off for the whole server, plus a per-user download permission in the Add User and Edit User forms. A user can download only when both are on; admins can always download. When downloads are off site-wide, the Add User and Edit User forms show a note next to the permission saying it has no effect until downloads are turned back on.

## Changed

- Home rails and the series and volume recommendation lanes now share a single rail macro (`partials/rail.html`) for their heading, optional action, and horizontal scroller, replacing about a dozen hand-copied versions of the same markup. Pinned Libraries and Smart Lists keep their own markup.
- All content rails now use the same card spacing. Want to Read, Recently Added Series, Recently Updated Series, and the series and volume recommendation lanes previously used wider spacing than the other rails.
- Comic cards in the Critically Acclaimed, Top Rated on Parker, and Smart List rails are now the same size as comic and series cards in the other Home rails. They were previously about 10% smaller.
- Kavita migration preview, discard, and run requests now execute in FastAPI's worker threadpool, and uploaded databases are staged in bounded chunks rather than copied into one large in-memory buffer.
- OPDS downloads now follow the download settings. Users who aren't allowed to download get a 403 from the OPDS download route, and their OPDS feeds leave out download links. OPDS readers open comics by downloading them, so these users can no longer read through OPDS.
- The Add User form now shows Require password change on first login right after the password field, matching the Edit User form. It was previously below the Administrator option.
- In the Add User and Edit User forms, clicking a library's name under Allowed Libraries now checks its box, and a Select all checkbox above the list checks or clears every library at once. It shows a dash when only some are checked and only appears when there is more than one library.

## Fixed

- Fixed the first card in each content rail being indented from the rail heading. Cards now line up with the heading on Home, series, and volume pages.
