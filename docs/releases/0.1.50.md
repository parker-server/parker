# Parker 0.1.50 Release Notes

Status: Draft

## Added

## Changed

- Page routes and the series, volume, comic, reading progress and reader APIs now run as plain functions in the server's thread pool instead of on its event loop, so a slow database call in one of them no longer stalls every other request in that worker. This is the first batch of the conversion planned in `docs/async-route-conversion-scope.md`; 65 routes are converted.

## Fixed

- The reader now sends one reading progress save at a time. Turning pages quickly could send overlapping saves that counted some pages twice in reading stats and Year in Review, or saved progress a page behind where the reader stopped. Page turns made while a save is running now go out as one save of the latest page, and a save still waiting is sent when the reader is closed.
- Fixed a browser test that left an extra comic in the shared test volume, which made the two cover browser lazy-loading tests fail whenever they ran after it.
