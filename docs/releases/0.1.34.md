# Parker 0.1.34 Release Notes

Status: Released

`0.1.34` is a focused Reader patch release that restores hover affordances on reader controls, fixes paged image fit behavior, and removes a misleading fit control from Long View.

## Added

- Added focused browser coverage for paged Reader fit-mode sizing and Long View fit-control visibility.

## Changed

- Reader image fit controls now only appear in paged mode, avoiding non-functional Fit Screen / Fit Width / Fit Height options in Long View.

## Fixed

- Fixed Reader navigation icon hover labels by restoring explicit titles on previous/next issue and previous/next page controls.
- Fixed paged Reader Fit Width and Fit Height behavior so explicit fit choices are no longer clamped back into the same viewport-constrained result as Fit Screen.
