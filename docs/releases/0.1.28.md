# Parker 0.1.28 Release Notes

Status: Unreleased

`0.1.28` is Parker's follow-up maintenance release focused on keeping background job history bounded as servers run for longer periods.

## Added

- Added configurable job-history retention through the `jobs.retention_days` system setting, defaulting to 30 days.
- Added global cleanup pruning for completed and failed background job history older than the configured retention window.
- Added focused service and settings coverage for terminal job pruning, active job preservation, and retention validation.
- Added paginated metadata detail endpoints for series and volume tag groups.

## Changed

- Admin System Maintenance now labels the manual cleanup action as `Database Cleanup` and describes its full scope, including old completed or failed job history.
- Job-history retention can no longer be disabled from settings; the value must be at least 1 day, and cleanup defensively clamps lower stored values to 1 day.
- Global cleanup summaries now include the number of old job-history rows removed.
- Series and volume pages now lazy-load Details tab metadata in small chunks when the tab is opened, with expanded groups able to collapse back to the first chunk.
- Cover Browser manifests now page cover entries and lazy-load additional chunks as users scroll or advance through oversized runs.
- Advanced Search now exposes an explicit sort order selector and resets each sort field to its natural default direction, such as Series Name A-to-Z and Date Added newest-first.

## Fixed

- Fixed unbounded `scan_jobs` growth by pruning stale completed and failed job rows during global cleanup while preserving pending and running jobs.
- Fixed avoidable latency and oversized responses for very large series or volumes with extensive metadata tags.
- Fixed timeline reading-list context pills so list order reads as `Part N` instead of looking like a canonical issue number.
- Fixed comic detail responses and pages exposing local filesystem paths to non-admin users.
- Fixed Advanced Search Series Name sorting appearing reversed after switching away from the default Date Added sort.
- Fixed library cards and library API responses exposing library root paths to non-admin users.
- Fixed decade-grouped Library Timeline views so year labels remain sticky while scrolling, matching non-decade timeline behavior.
