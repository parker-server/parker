# Parker 0.1.36 Release Notes

Status: Draft

`0.1.36` is a focused patch release for making archive cover detection more explicit, easier to test, and more reliable for odd scan naming patterns, while improving scan job diagnostics in the admin job history and introducing first-pass Cover Murals.

## Added

- Added score-level archive ordering coverage that verifies named cover signals and penalties instead of relying only on incidental tuple ordering.
- Added Cover Murals so users can collect selected comics from the picker, arrange their covers on a snap canvas, persist mural ownership and layout, and export the result as a PNG.
- Added Cover Mural export controls for compact source-size output, layout-sized output, scaling, spacing, separate horizontal/vertical overlap, and overlap stacking order.
- Added admin-enforced password changes for temporary-password workflows, including user-management controls, login redirection, and a dedicated forced-change screen before normal app or OPDS access.

## Changed

- Reworked archive page ordering around an explicit `PageSortScore` model with page roles, page-index detection, named cover signals, named penalty signals, natural filename ordering, and archive-order fallback.
- Archive cover detection now treats joined covers, inside front covers, preview/header pages, and back-cover markers as named signals so future edge cases can be reasoned about directly.
- Expanded the admin Job History scan details modal to show skipped and error counts alongside imported, updated, and deleted counts.
- Cover Mural exports now use the original archive cover page by default in compact mode, trimming unused canvas space while still allowing spacing, directional overlap, stack ordering, and scale adjustments.
- User password updates now reject reusing the current password and clear any outstanding forced-change requirement after a successful change.

## Fixed

- Fixed cover selection when a bare page-zero cover appears next to a joined or suffixed page-zero image, such as `HybridsSpecial001-00.jpg` before `HybridsSpecial001-00A.jpg`.
- Fixed cover selection when an appended numeric page-zero variant appears next to the exact bare page-zero cover, such as `Earth4-V2-001-00.jpg` before `Earth4-V2-001-00-35.jpg`, without treating the appended number as a content label.
- Fixed preview/header filenames so late-archive extras like `WayofRat23NegWarPreviewHeader.jpg` do not outrank numbered page images like `WayofRat23-01.jpg`.
- Fixed two-page-cover filenames so joined-cover images like `The First - 005 Pg00z (2 page cover).jpg` do not outrank the base `Pg00` cover.
- Fixed front-cover token handling so `fcover` is recognized as a cover signal while `ifcover` and `IFC` remain inside-front-cover penalties.
- Fixed scan job summaries so per-file error details collected during metadata processing are saved and shown in the Job History details modal instead of only displaying a total error count.
- Fixed watch mode so read-only filesystem events such as opening a comic file do not start a scan batch window.
