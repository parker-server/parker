# Parker 0.1.31 Release Notes

Status: Released

`0.1.31` starts with metadata-health, navigation alignment, reader-mode visibility, and cover-browsing fixes so report drill-downs, character links, incognito sessions, and comic covers communicate the right destination or state.

## Added

- Added a persistent incognito indicator to the reader title bar so readers can tell progress and bookmark changes will not be saved after the initial toast disappears.
- Added comic-detail cover clicks that open the series Cover Browser at that comic's cover, with existing cover-browser links carrying an explicit default starting cover.

## Changed

- None yet.

## Fixed

- Fixed the Metadata Health `Missing Release Year` drill-down so Advanced Search treats `field=year&operator=is_empty` as `Comic.year IS NULL` instead of dropping the filter and returning unrelated comics.
- Fixed the dashboard Detailed Statistics Top Characters links so they open the Library Timeline for that character instead of Advanced Search, matching character-tag navigation elsewhere.
- Fixed series and volume first-cover selection, Cover Browser ordering, and reader navigation for comic runs where release-date metadata would otherwise place later issue numbers before earlier ones.
- Fixed comic-detail Cover Browser launches so closing the browser returns to the originating comic detail page instead of the broader series page.
- Fixed the series-detail Synopsis `Read More` control so it appears only when the rendered summary is actually clipped, not just when the summary exceeds a character-count threshold.
