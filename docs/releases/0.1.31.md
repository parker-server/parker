# Parker 0.1.31 Release Notes

Status: In Progress

`0.1.31` starts with metadata-health, navigation alignment, and reader-mode visibility fixes so report drill-downs, character links, and incognito sessions communicate the right destination or state.

## Added

- Added a persistent incognito indicator to the reader title bar so readers can tell progress and bookmark changes will not be saved after the initial toast disappears.

## Changed

- None yet.

## Fixed

- Fixed the Metadata Health `Missing Release Year` drill-down so Advanced Search treats `field=year&operator=is_empty` as `Comic.year IS NULL` instead of dropping the filter and returning unrelated comics.
- Fixed the dashboard Detailed Statistics Top Characters links so they open the Library Timeline for that character instead of Advanced Search, matching character-tag navigation elsewhere.
